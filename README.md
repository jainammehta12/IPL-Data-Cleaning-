## Project Definition

This project focuses on analyzing IPL cricket data from 2008 onwards
using Python.

The main objective of this project is to clean the dataset by handling
missing values, duplicate records, incorrect data types and identifying
possible outliers.

After cleaning the data, exploratory data analysis will be performed to
understand team performance, player performance, toss decisions and IPL
match trends.

------------------------------------------------------------------------

## Dataset

The project uses the IPL Complete Dataset (2008--2020) obtained from
Kaggle.

The dataset contains match-level and ball-by-ball information such as:

-   Teams
-   Players
-   Venues
-   Toss decisions
-   Match results
-   Runs
-   Wickets
-   Player performance

### Dataset Source

Kaggle: IPL Complete Dataset 2008--2020

https://www.kaggle.com/datasets/patrickb1912/ipl-complete-dataset-20082020

## Data Cleaning

The following data-cleaning techniques will be applied:

-   Identify and handle missing values
-   Detect and remove duplicate records where appropriate
-   Check and correct incorrect data types
-   Convert date columns into proper datetime format
-   Detect potential outliers using statistical methods and box plots
-   Verify the cleaned dataset before analysis

------------------------------------------------------------------------

## Proposed Visualizations

The project will include the following visualizations:

1.  **Matches Played per Season**\
    To analyze the number of matches played in each IPL season.

2.  **Matches Won by Teams**\
    To compare the performance of different IPL teams.

3.  **Toss Decision Distribution**\
    To analyze whether teams prefer batting or fielding after winning
    the toss.

4.  **Toss Winner vs Match Winner**\
    To study the relationship between winning the toss and winning the
    match.

5.  **Top 10 Player of the Match**\
    To identify players who received the most Player of the Match
    awards.

6.  **Top 10 Run Scorers**\
    To identify the highest run-scoring players.

7.  **Top 10 Wicket Takers**\
    To identify the players who took the most wickets.

8.  **Matches by City**\
    To analyze the distribution of IPL matches across different cities.
